# @yysubs/vue-fluent-kit

基于 token 的 Vue 3 组件库，样式用纯 CSS，组件类名统一 `vfk-` 前缀。开发中，还没发布。

## 开发

```bash
pnpm install
pnpm dev     # 本地预览 src/demo
pnpm build   # 构建 dist
pnpm test    # 单元测试
```

## 结构

- `src/components/`：组件
- `src/styles/index.css`：token 默认值，变量前缀 `--vfk-`
- `src/demo/`：开发预览，不进构建
